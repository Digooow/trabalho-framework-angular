O que é?
-Angular é um framework de código aberto baseado em TypeScript, ele é uma reescrita completa do AngularJS produzida pela mesma equipe

Para que serve e o que resolve?
-Angular é utilizado para criar aplicações web dinâmicas, modernas e escalaveis como Single Page Applications (SPA), o framework oferece uma plataforma robusta e escalavel, permitindo a reutilização de código e manutenção facil de API's complexas

Quem criou e em que ano surgiu?
-Ele foi lançado em 14 de setembro de 2016 pela Equipe Angular do Google em conjunto de corporações e individuos

Como evoluiu e onde é utilizada?
-Originalmente sendo uma releitura do AngularJS (1.X), foi nomeado como Angular 2 e posteriormente nomeado apenas como Angular. Atualmente ele ta na versão 22.0.0, sendo sua ultima atualização feit aem 3 de junho de 2026. 
-Ele é utilizado como framework para aplicações web (API's)

O que é necessario instalar para começar?
-Para instalar o Angular, é necessario instalar o node.js e a instalação do Angular em npm no terminal

Como criar um projeto do zero?
-Para criar um projeto Angular é necessario rodar o comando "ng new <nome desejado>", escolher se a API tera uma URL ou multiplas e qual pré-processador CSS que você usará. Após isso o terminal gerará todas as dependencias e arquivos necessarios para iniciar o projeto
